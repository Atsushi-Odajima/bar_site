# 販促用の文章（制作見本「炉端と酒 灯」）

※ 実際の受注実績・集客効果・売上や予約件数の変化は記載していません。料金・納期・保守内容は含めていません。

## 紹介文（約170文字）

炉端焼きと地酒の居酒屋を想定した、架空店舗の制作見本です。炭火で焼く料理の写真と落ち着いた文字組みで、お店の雰囲気がスマホでも伝わるように仕上げました。価格入りのお品書き、営業時間、電話・予約のボタンは、開いてすぐ分かる位置に置いています。人数・日付・時間・席を選ぶWeb予約と、店舗側の予約管理画面も、実際に操作して体験していただけます。

## オーナー様向けの特徴（3項目）

1. **スマホで迷わない作り**
   営業時間・定休日・価格を大きめの文字で表示し、画面の下には「電話・予約・LINE・地図」のボタンを常に表示します。年配のお客様にも押しやすいボタンの大きさにしています。

2. **お店の雰囲気が伝わる見せ方**
   暖簾が開くオープニング、和紙のお品書き、黒板の「今日のおすすめ」など、和の演出を控えめに取り入れています。演出は表示速度を落とさないよう軽く作り、動きを減らす設定の端末では止まります。

3. **予約と管理の流れを体験できる**
   お客様は3ステップで予約でき、定休日や満席の時間は選べません。お店側は日付ごとの予約一覧で、確定・来店済み・キャンセルを切り替えられます。
   ※見本では予約はブラウザ内に保存されるだけです。本番では予約データの保存先、ログイン、通知の設定が別途必要です。

## この見本で体験できること

- スマホ・PC それぞれの見え方（PC は写真と縦書きを使った非対称のレイアウト、スマホは読みやすい1列）
- お品書きのカテゴリ切り替え（焼き物／刺身／一品／〆・甘味／日本酒／ハイボール・焼酎）
- Web 予約の流れ（人数・日付・時間・席 → お客様情報 → 確認 → 完了。「サンプル情報を入力する」ボタンつき）
- 店舗側予約管理画面（パスワード `demo`。日付別一覧・ステータス変更・詳細・デモデータの初期化）
- 電話・LINE・SNS ボタンを押したときの動作説明（見本のため実際には発信・移動しません）

## 本番導入時に設定・開発すること

- 店名・写真・メニュー・価格・営業時間などの差し替え（お店の写真撮影の手配を含む）
- 電話番号・LINE 公式アカウント・Instagram・X・食べログ・Google マップの実際のリンク設定
- 予約データの保存先（データベース）と、管理画面のログイン・権限設定
- 予約の通知（お店への新着通知、お客様への確認メールなど）
- 実際の席数に合わせた空席管理と、二重予約の防止
- プライバシーポリシーの掲載、検索エンジン向けの設定（店舗情報の構造化データなど）
